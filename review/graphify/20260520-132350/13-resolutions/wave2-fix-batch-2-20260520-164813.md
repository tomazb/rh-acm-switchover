### `acm_preflight_report` check mode skips path validation and reports unchanged

- Severity: Minor
- Source files:
  - `ansible_collections/tomazb/acm_switchover/plugins/modules/acm_preflight_report.py`
  - `ansible_collections/tomazb/acm_switchover/tests/unit/plugins/modules/test_acm_preflight_report.py`
- Root cause: `acm_preflight_report` skipped `write_report()` entirely when `module.check_mode` was true, so it also skipped `write_json_artifact()` path validation and always returned `changed=False` with `path=None`.
- Fix: Route normal and check-mode paths through `write_json_artifact(..., check_mode=module.check_mode)` and return the shared writer's `changed` and `path` values.
- Tests added or updated:
  - Added a check-mode unsafe-path test to verify path traversal still fails before exit.
  - Added a check-mode planned-change test to verify a valid destination returns `changed=True`, returns the destination path, and does not create the file.
  - Added a check-mode unchanged test to verify a matching existing artifact returns `changed=False` with the destination path.
- Verification commands:
